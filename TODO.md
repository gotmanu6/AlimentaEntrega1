# Evoluções futuras

## Alimenta

- Autenticação e perfis de acesso para uso além da PoC local.
- Desativação de pontos ou transações para concorrência entre coleções.
- Cancelamento auditável de reservas, inclusive vencidas, e entrega parcial.
- Paginação, índices orientados a volume e notificações.
- Avaliação com usuários reais e medição de impacto social.

Os itens abaixo se referem originalmente ao exemplo didático de linguagens.

- paginação;
- ordenação;
- busca por nome;
- filtros;
- validação de duplicidade;
- `PATCH`;
- autenticação;
- autorização;
- métricas;
- observabilidade;
- integração contínua (CI);
- GitHub Actions;
- controle de versões da API;
- auditoria.
